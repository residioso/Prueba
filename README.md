# 🚀 Proyecto de Prueba con Git

Este es un proyecto inicial desarrollado para dominar el flujo de trabajo con **Git** y **GitHub**. Contiene una estructura web básica y registros de inicialización.

## 🛠️ Tecnologías Utilizadas
* **HTML5** - Estructura básica de la página web.
* **Git** - Control de versiones local.
* **GitHub** - Alojamiento del repositorio en la nube.

## 📁 Estructura del Proyecto
El repositorio contiene los siguientes archivos esenciales:
* `index.html`: Estructura web inicial del proyecto.
* `info.txt`: Registro de inicio del proyecto.

## 🚀 Cómo Ejecutar el Proyecto Localmente

1. Clona este repositorio en tu máquina:
   ```bash
   git clone https://github.com
   ```
2. Navega a la carpeta del proyecto:
   ```bash
   cd Prueba
   ```
3. Abre el archivo `index.html` en tu navegador favorito.
